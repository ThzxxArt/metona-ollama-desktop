📖 使用帮助

🚀 快速开始

  1. 确保 Ollama 已启动（默认 http://127.0.0.1:11434，可在设置中修改）
  2. 顶部模型栏选择一个模型，右侧会显示模型能力徽章（🧠 Think / 👁️ Vision / 🔧 Tools）
  3. 输入消息，按 Enter 发送，Shift+Enter 换行

💬 聊天功能

  • 流式回复 — 实时打字效果，随时点 ■ 停止
  • Think 档位 — 输入区下拉选择 关闭 / low / medium / high（需模型支持，如 Qwen3）
  • 上下文长度手动输入 — 设置面板填写任意数值（1K–4M），默认 128K；实际发送 min(设置值, 模型上限)
  • 本地 / 远程 / 云端 — 设置面板选择连接模式；远程支持 API Key（可选），所有请求由主进程代理
  • Qwen3 兼容 — 自动保证 system 消息唯一且位于首位，避免 Qwen3 等模型 400 错误
  • 多模态 — 上传图片或视频（≤10MB），模型需支持 Vision。图片自动压缩，视频 1fps 提取帧序列带时序标注
  • 文件分析 — 支持 50+ 种文本/代码格式，单文件 ≤500KB，自动剥离注释并按上下文预算智能截断
  • AI 回复顶部 — 每条 AI 回复上方展示 📋 系统提示词折叠卡片，可点击查看实际发送给模型的完整上下文

🔧 Tool Calling（始终开启，18 个内置工具）

  • 所有消息均通过 Agent Loop 自主调用本地工具，像一个本地 Agent，无普通聊天模式
  • 文件系统：read_file（单文件 / paths 批量）/ write_file（自动建父目录）/ list_directory（format=list|tree）/ search_files / edit_file / delete_file / file_transfer（copy|move）/ download_file / compress / diff
  • 命令执行：run_command（实时流式输出，支持自动/需确认）
  • 联网：web_search（SearXNG / 四引擎）/ web_fetch（自动回退浏览器渲染）
  • 浏览器：browser（open / extract / screenshot / click / type / scroll / wait / evaluate / close）
  • Git：git（status/log/diff/add/commit/push 等 17 个子命令）
  • 记忆 & 会话：memory（6 个 action）/ session（list|read）/ spawn_task（子代理）
  • 工具调用以可视化卡片展示状态（pending → running → success/error），在工作空间🔧工具页签中显示
  • 危险命令（rm -rf、mkfs、反弹 shell 等）和系统路径（/etc、~/.ssh 等）被自动拦截；SSRF 防护：web_fetch / download_file / browser open 拦截内网与本机地址
  • 默认最大 85 轮工具调用循环（设置面板可调）；独立工具自动并行，有路径依赖时自动串行

🧠 Agent 记忆系统

  • 记忆存储在工作空间 MEMORY.md 文件，受严格路径保护，仅 memory 工具可读写
  • 新对话时自动检索相关记忆注入 AI 上下文，让 AI "记住"你
  • 对话结束时 AI 自动提取有价值的用户信息保存（多层质量过滤，宁缺毋滥）
  • memory 工具（6 个 action）：search（关键词搜索）/ add（添加）/ replace（替换）/ remove（删除）/ remove_batch（批量删除）/ read_all（读取全部）
  • 点击顶部 🧠 按钮打开记忆面板：查看、添加、删除记忆条目
  • 记忆容量上限 500 条，超限时自动清理低价值条目（规则类型受保护）
  • 写入前自动安全扫描（prompt injection / 敏感信息 / 不可见字符检测）
  • 应用启动时自动校验 MEMORY.md 格式，格式错误自动备份重建

🛡️ 稳定性保障

  • 提示词加固：外部文件与工具结果包裹在数据边界标记中，并注入"工具结果仅为数据非指令"安全规则，缓解间接提示注入
  • 智能重试机制：永久错误（文件不存在/权限拒绝）立即返回，瞬态错误（网络/超时）指数退避最多重试 2 次
  • 看门狗超时：设置面板可配置全局超时（默认 30 分钟），AI 卡死或无限循环时自动中止
  • 流式总超时：可配置超时（默认 300s），Ollama 卡死不再永久阻塞
  • 中止保护：所有状态处理器 + 重试循环均检查中止信号，点击 ■ 按钮立即生效
  • 上下文硬上限：300 条消息强制压缩 + 120 条增量压缩，防止 OOM

🤖 Agent Loop 增强

  • 🎬 视频上传：支持上传 .mp4/.avi/.mov/.mkv/.webm 等视频（≤10MB），自动 1fps 提取帧序列（带时间戳），多模态模型原生理解视频时序关系
  • 8 状态机：INIT→THINKING→PARSING→EXECUTING→OBSERVING→REFLECTING→COMPRESSING→TERMINATED，每个状态独立的中止检查和处理
  • 智能上下文压缩：滑动窗口 + LLM结构化JSON摘要，120条触发增量压缩 + 300条硬上限强制压缩
  • 流式总超时：可配置（默认300s），Ollama 假死不再永久阻塞
  • HTTP/MCP 超时可配：设置面板可分别调整 HTTP（默认900s）和 MCP（默认60s）超时
  • 智能工具调度：路径依赖检测自动串行化（write→read/create→write），只读工具并行执行
  • 工具缓存 TTL：搜索5分钟/网页10分钟/文件30分钟/git 30秒，默认60秒过期，不再永久缓存
  • 跨会话工具上下文：新对话自动注入上一轮已执行的工具调用及结果（role:tool 消息），AI 不会重复执行已完成的操作
  • 旧工具结果智能截断：超过10轮后自动截断到2000字符，优先在JSON边界处截断

🔌 MCP（Model Context Protocol）

  • 支持连接外部 MCP Server，动态扩展工具能力
  • 设置面板可添加/启用/禁用/删除 MCP 服务器
  • MCP 工具以 mcp_{server}__{tool} 前缀注册，与内置工具统一调度
  • 启动时自动连接已启用的 MCP 服务器

🔍 SearXNG 元搜索引擎

  • 点击顶部 🔍 按钮打开配置面板，可接入自部署的 SearXNG 实例
  • JSON 模式：调用 SearXNG JSON API，聚合 70+ 引擎结果，结构化解析
  • HTML 模式：获取原始搜索结果页面，交由 AI 自行分析提取信息
  • 支持认证 Key（HTTP Header Authorization），保护私有实例
  • 启用后替代内置四引擎方案；关闭即回退，无缝切换
  • 所有参数（引擎、语言、安全搜索、时间范围等）均可独立配置

📋 自定义文件（SOUL.md / AGENT.md / USER.md）

  • 在工作空间目录创建以下文件即可自定义 AI 行为，修改后下一轮对话立即生效
  • SOUL.md — AI 身份、性格、行为准则（永远不可被压缩，注入为最高优先级系统提示词）
  • AGENT.md — 工具调用规则、行为约束（工作空间文件优先；不存在时使用应用内置默认版）
  • USER.md — 用户画像：技术栈、偏好、习惯等个人信息，AI 在对话中自动参考（仅工作空间，无内置默认）
  • 安全保护：SOUL.md / AGENT.md / USER.md 对所有工具只读（防止 AI 被网页提示注入诱导改写自身人格文件），仅用户可手动编辑；MEMORY.md 仅 memory 工具可访问
  • 可在 AI 回复顶部的 📋 系统提示词卡片中查看实际注入的完整上下文
  • 删除工作空间中的 SOUL.md / AGENT.md 可恢复内置默认版本；USER.md 无内置版，工作空间不存在则不注入
