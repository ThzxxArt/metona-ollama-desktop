📖 使用帮助

🚀 快速开始

  1. 确保 Ollama 已启动（默认 http://127.0.0.1:11434，可在设置中修改）
  2. 顶部模型栏选择一个模型，右侧会显示模型能力徽章（🧠 Think / 👁️ Vision / 🔧 Tools）
  3. 输入消息，按 Enter 发送，Shift+Enter 换行

💬 聊天功能

  • 流式回复 — 实时打字效果，随时点 ■ 停止
  • Think 推理 — 下方 Think 按钮切换，让模型展示深度思考过程（需模型支持，如 Qwen3）
  • 上下文长度手动控制 — 设置面板下拉选择（128K / 256K / 512K / 1M），默认 128K。模型栏显示当前配置值，下拉框中每个模型旁显示其自身的上下文长度
  • Qwen3 兼容 — 自动保证 system 消息唯一且位于首位，避免 Qwen3 等模型 400 错误
  • 多模态 — 上传图片或视频（≤10MB），模型需支持 Vision。图片自动压缩，视频 1fps 提取帧序列带时序标注
  • 文件分析 — 支持 50+ 种文本/代码格式，单文件 ≤500KB，自动剥离注释并按上下文预算智能截断
  • AI 回复顶部 — 每条 AI 回复上方展示 📋 系统提示词折叠卡片，可点击查看实际发送给模型的完整上下文

🔧 Tool Calling（始终开启）

  • 所有消息均通过 Agent Loop 自主调用本地工具，像一个本地 Agent，无普通聊天模式
  • 32 个工具，分为 9 类：
    • 文件系统（13 个）：read_file / write_file / list_directory / search_files / create_directory / delete_file / move_file / copy_file / edit_file / tree / download_file / read_multiple_files / compress
    • 命令执行（1 个）：run_command（实时流式输出，支持自动/需确认/禁用三种模式，可配置超时）
    • 联网搜索（2 个）：web_search（支持 SearXNG 元搜索引擎 JSON API / 四引擎 HTML 解析，双模式可切换）/ web_fetch（反爬headers+UA自动切换+自动回退浏览器渲染）
    • Git（1 个）：git（17 个子操作，push/pull/clone 内置60-120s超时保护）
    • 浏览器控制（9 个）：browser_open / browser_screenshot / browser_evaluate / browser_extract / browser_click / browser_type / browser_scroll / browser_wait / browser_close
    • 记忆 & 会话（5 个）：memory（统一记忆管理，5 个 action）/ session_list / session_read / spawn_task / plan_track
    • 系统工具（1 个）：calculator
  • read_file 支持 binary模式读取/base64解码/字节分页/2000行默认+截断hint自动续读
  • write_file 支持 base64写二进制文件/mode(overwrite+append)合并append_file功能/10MB
  • edit_file 支持 use_regex 正则替换
  • search_files 支持正则表达式搜索（use_regex=true）
  • browser_screenshot 支持全页面截图+元素截图
  • browser_extract 支持CSS选择器提取特定区域
  • new browser_wait 等待元素出现或定时等待
  • 所有写操作工具均支持三档开关：自动/需确认/禁用（浏览器工具始终自动执行）
  • 危险命令（rm -rf、mkfs、反弹 shell 等）和系统路径（/etc、~/.ssh 等）被自动拦截
  • 工具调用以可视化卡片展示状态（pending → running → success/error），在工作空间🔧工具页签中显示
  • 默认最大 85 轮工具调用循环（设置面板可调），上下文使用率>80%时自动缩减到3轮
  • 独立工具自动并行执行（11个只读工具加入并行白名单），有依赖关系的工具串行执行

🧠 Agent 记忆系统

  • 记忆存储在工作空间 MEMORY.md 文件，受严格路径保护，仅 memory 工具可读写
  • 新对话时自动检索相关记忆注入 AI 上下文，让 AI "记住"你
  • 对话结束时 AI 自动提取有价值的用户信息保存（多层质量过滤，宁缺毋滥）
  • memory 工具（5 个 action）：search（关键词搜索）/ add（添加）/ replace（替换）/ remove（删除）/ read_all（读取全部）
  • 点击顶部 🧠 按钮打开记忆面板：查看、添加、删除记忆条目
  • 记忆容量上限 500 条，超限时自动清理低价值条目（规则类型受保护）
  • 写入前自动安全扫描（prompt injection / 敏感信息 / 不可见字符检测）
  • 应用启动时自动校验 MEMORY.md 格式，格式错误自动备份重建

📋 Plan Mode（计划模式）

  • 点击输入框上方 📋 按钮开启 Plan Mode（开关式）
  • 开启后，AI 先生成执行计划（Markdown 渲染弹窗），用户批准后才开始执行
  • 计划批准后自动初始化追踪器，每个步骤完成后调用 plan_track 工具标记进度
  • 系统提示词自动注入当前进度状态，AI 始终知道还剩多少步未完成
  • 多步骤任务防遗忘：自动检测用户请求中的动作动词，对比已完成步骤，注入提醒
  • 关闭 Plan Mode 后恢复正常 Agent Loop 模式
  • 仅 Plan 模式 下 plan_track 工具可见，避免污染普通模式的工具列表

🛡️ 抗幻觉 & 稳定性

  • 5 层防御体系：系统提示词加固 → 任务感知 → 中途幻觉检测（中英双语规则覆盖全部工具类别）→ 进度锚点 → 完成闸门（6 项检查，幻觉/注入 → 阻断，质量/效率 → 咨询）
  • 完成闸门：对话结束前自动审查 AI 回复，检测工具幻觉和 prompt injection，阻断有问题的回复
  • 中英双语检测规则：覆盖中英文模型输出，防止 AI 声称执行了未调用的工具
  • 智能重试机制：永久错误（文件不存在/权限拒绝）立即返回，瞬态错误（网络/超时）指数退避最多重试 2 次
  • 看门狗超时：设置面板可配置全局超时（默认 30 分钟），AI 卡死或无限循环时自动中止
  • 流式总超时：可配置超时（默认 300s），Ollama 卡死不再永久阻塞
  • 中止保护：所有状态处理器 + 重试循环均检查中止信号，点击 ■ 按钮立即生效
  • 上下文硬上限：200 条消息强制压缩 + 120 条增量压缩，防止 OOM

🤖 Agent Loop 增强

  • 🎬 视频上传：支持上传 .mp4/.avi/.mov/.mkv/.webm 等视频（≤10MB），自动 1fps 提取帧序列（带时间戳），多模态模型原生理解视频时序关系
  • 8 状态机：INIT→THINKING→PARSING→EXECUTING→OBSERVING→REFLECTING→COMPRESSING→TERMINATED，每个状态独立的中止检查和处理
  • 智能上下文压缩：滑动窗口 + LLM结构化JSON摘要，120条触发增量压缩 + 300条硬上限强制压缩
  • 流式总超时：可配置（默认300s），Ollama 假死不再永久阻塞
  • HTTP/MCP 超时可配：设置面板可分别调整 HTTP（默认30s）和 MCP（默认60s）超时
  • 智能工具调度：路径依赖检测自动串行化（write→read/create→write），只读工具并行执行
  • 工具缓存 TTL：搜索5分钟/网页10分钟/文件30分钟/git 30秒，默认60秒过期，不再永久缓存
  • Plan Mode 断点续传：中止后可恢复未完成的计划，进度自动保存
  • Token 感知迭代预算：上下文使用率>80%时自动缩减剩余轮次到3轮
  • 跨会话工具上下文：新对话自动注入上一轮已执行的工具调用及结果（role:tool 消息），AI 不会重复执行已完成的操作
  • 旧工具结果智能截断：超过10轮后自动截断到2000字符，优先在JSON边界处截断

🔌 MCP（Model Context Protocol）

  • 支持连接外部 MCP Server，动态扩展工具能力
  • 设置面板可添加/启用/禁用/删除 MCP 服务器
  • MCP 工具以 mcp_{server}__{tool} 前缀注册，与内置工具统一调度
  • 启动时自动连接已启用的 MCP 服务器

🔍 SearXNG 元搜索引擎

  • 点击顶部 🔍 按钮打开配置面板，可接入自部署的 SearXNG 实例
  • JSON 模式：调用 SearXNG JSON API，聚合 70+ 引擎结果，结构化解析
  • HTML 模式：获取原始搜索结果页面，交由 AI 自行分析提取信息
  • 支持认证 Key（HTTP Header Authorization），保护私有实例
  • 启用后替代内置四引擎方案；关闭即回退，无缝切换
  • 所有参数（引擎、语言、安全搜索、时间范围等）均可独立配置

📋 自定义文件（SOUL.md / AGENT.md / USER.md）

  • 在工作空间目录创建以下文件即可自定义 AI 行为，修改后下一轮对话立即生效
  • SOUL.md — AI 身份、性格、行为准则（永远不可被压缩，注入为最高优先级系统提示词）
  • AGENT.md — 工具调用规则、链式调用模式、核心约束（仅从工作空间加载，有则注入，无则不注入）
  • USER.md — 用户画像：技术栈、偏好、习惯等个人信息，AI 在对话中自动参考（仅工作空间，无内置默认）
  • 可在 AI 回复顶部的 📋 系统提示词卡片中查看实际注入的完整上下文
  • SOUL.md 删除工作空间文件可恢复内置默认版本；AGENT.md / USER.md 无内置版，工作空间不存在则不注入
